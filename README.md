# 🔐 PDF Password Recovery Using John the Ripper

## 📌 Project Overview

This project demonstrates a practical cybersecurity lab focused on understanding PDF password protection, hash extraction, and password recovery techniques using **John the Ripper**.

The objective was to understand how password-protected PDF documents can be tested in an authorized environment and why strong passwords are important for information security.

This project is part of my hands-on cybersecurity learning journey.

---

## 🎯 Project Objectives

- Understand how PDF password protection works.
- Learn how password hashes are extracted from PDF documents.
- Install and configure John the Ripper.
- Practice authorized wordlist-based password testing.
- Understand dictionary attacks and password vulnerabilities.
- Learn practical password security techniques.

## 🔒 Security and Ethical Considerations

This exercise was conducted for educational purposes using an authorized practice document.

Password recovery tools should only be used on files that you own or have explicit permission to test.

Do not publish private password hashes, recovered passwords, or confidential documents.
